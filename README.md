Key Features and Project Goals:

Play Mario Party 1, 2 and 3 from one compilation game

Quality of life improvements and rebalancing of the games

All Games:

Default turns: 15, 20, 30 and custom turns (MP1 and MP2 for now)

Practice mode added to all games and game modes (Some single player modes pending)

Distance to the star and an indicator of the board space you will land at all board junctions (MP1 for now)

Message speed set to FAST for all modes

All coins and stars collected in any game get saved into MP1

View all game states and mini game records from Mushroom Village by pressing START

Added a requirement that all human players press START before a mini game starts (MP1 for now)



Mario Party 1 Rebalance Changes:

All mini-games, you no longer lose coins if you lose a mini-game

Bash n Cash, Grab Bag and Crane Game, cap of 30 coins, no players lose coins

Single player mini-games by CPU players, mini-game is skipped

All items available to purchase in the Mushroom Village shop

Uncapped stars to 9,999 and coins to 99,999

Windows x86-64 Installation Instructions

Mario Party N64 Collection Windows x86-64 Installation Instructions

You need your own Mario Party 1, 2 and 3 (USA) ROMs (.z64). None are included.

1. Unzip anywhere and run "Mario Party Collection.exe".
2. Mario Party 1 asks for its ROM the first time: pick your Mario Party (USA) .z64.
3. In Mario Party 1, take the Warp Pipe (or the raft) and pick Mario Party 2 or 3:
   each asks for its own ROM the first time it starts.
4. After Mario Party 2's ROM is in, restart the collection once: some Mario Party 2
   pictures (practice-mode pills, the ready-up buttons) are taken from it at Mario Party 1's start.

Saves and settings live in %LOCALAPPDATA%\MarioPartyRecompiled, MarioParty2Recompiled,
MarioParty3Recompiled and MarioPartyCollection.
